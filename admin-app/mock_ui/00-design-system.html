💡 Design Principles & Best Practices

Performance

  • Paginate all list APIs (20 items default)
  • RTK Query auto-caches; avoid manual useEffect fetches
  • Debounce search input 300 ms before triggering query
  • Lazy-load product images with loading="lazy"
  • Code-split each route with React lazy + Suspense

Accessibility (WCAG 2.1 AA)

  • All form inputs have associated <label>
  • Error messages linked via aria-describedby
  • Modals trap focus; Esc closes them
  • Color contrast ratio ≥ 4.5:1 for text on white
  • Tables include scope="col" on <th>

Error States

  • Every RTK Query hook checks isError → show inline alert
  • Form field errors display below input (not toast)
  • Network errors show a retry button
  • 404 / empty states always show a helpful call-to-action

Scalability

  • Feature-folder structure: features/products/, features/orders/
  • Shared components in components/ui/ — never duplicate
  • Route constants in routes/routes.ts — single source of truth
  • All env vars via import.meta.env.VITE_*
