Active Nav Highlight

  • Use NavLink from react-router-dom v7 with className={({ isActive }) => ...}
  • Match on end prop for the root /dashboard route
  • Active item gets border-left: 3px solid lime-400
  • Badge counts (orders, inventory) come from dashboardApi.getDashboardStats()

Sidebar Collapse (Mobile / Compact)

  • Redux slice uiSlice.sidebarOpen boolean controls collapsed state
  • Collapsed: width 56 px, show only icon, tooltip on hover
  • Hamburger button in topbar toggles the slice
  • Below 768 px: sidebar overlays on top (fixed, z-100) with backdrop

Breadcrumb Generation

  • Derive from useMatches() (react-router-dom v7)
  • Each route defines handle: { breadcrumb: "Products" }
  • Auto-truncates to 2 levels: Section › Page
  • Dynamic segments (e.g. order ID) resolved from route params

Auth Guard Integration

  • ProtectedRoute.tsx wraps all authenticated routes via <Outlet />
  • Reads auth.status from Redux; redirects to /login if unauthenticated
  • AuthInitializer.tsx calls GET /api/admin/auth/me on mount to hydrate Redux from cookie
  • Loading state shows full-page spinner, not shell (avoids layout flash)
