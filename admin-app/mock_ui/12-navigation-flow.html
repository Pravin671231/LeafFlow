🛡️ Auth Guard Logic (ProtectedRoute)

App loads
AuthInitializer runs GET /api/admin/auth/me
loading state → full-page spinner
200 → admin data
Set auth.status = "authenticated"
Render shell + <Outlet />
401 → not authenticated
Set auth.status = "unauthenticated"
/login (replace history)
401 on any API call mid-session
RTK Query baseQuery refresh interceptor attempts token refresh
Retry OR redirect to /login
