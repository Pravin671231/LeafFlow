LeafFlow Buyer App — UI Proposal

Complete storefront wireframe suite · Stack: Next.js 16 App Router + TanStack Query + Zustand + Tailwind v4 + DaisyUI 5

How to use this proposal

  • Click any card to open the full-page wireframe for that screen.
  • Every page includes annotated zones, TanStack Query hook names, Zustand store notes and Next.js App Router hints.
  • The Design System defines the buyer-facing brand tokens — warmer, plant-inspired, consumer-friendly.
  • The Navigation Flow covers App Router layout nesting, auth guards, search-param routing, and checkout step machine.
Key differences from Admin App Full-width storefront layout (no sidebar) · Sticky header with cart badge · SSR/SSG pages via Next.js App Router · TanStack Query for async data (not RTK Query) · Zustand for cart + checkout step state · Google One Tap overlay · Mobile-first responsive grid · Public product pages (no auth required).
