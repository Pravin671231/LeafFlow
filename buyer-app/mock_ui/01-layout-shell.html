Next.js App Router Nesting

  • app/layout.tsx — root: fonts, metadata, providers
  • app/(shop)/layout.tsx — Header + Footer shell
  • app/(auth)/layout.tsx — centered auth card, no footer nav
  • app/(account)/layout.tsx — account sidebar + content
  • Each route segment has its own page.tsx

Google One Tap Integration

  • Mount <GoogleOneTap /> inside root layout
  • Shows floating credential prompt on any page
  • On credential: POST /api/buyer/auth/google/one-tap
  • If useMe() returns data → suppress One Tap
  • Dismiss: user clicks × or logs in via another method

Cart Badge (Zustand ↔ Header)

  • Header is a Client Component that subscribes to useCartStore(s => s.totalItems)
  • Zustand store persisted to localStorage via persist middleware
  • On login: call GET /api/buyer/cart → merge server cart into Zustand
  • Badge animates on add via CSS keyframe (scale 1 → 1.3 → 1)

Auth Middleware (Next.js)

  • middleware.ts at repo root
  • Protected matchers: /checkout, /orders, /profile
  • Reads access token from httpOnly cookie
  • On missing/expired: redirect to /login?redirect=<path>
  • After login, redirect back to redirect param value
