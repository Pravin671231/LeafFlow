🗃️ Zustand Store Design

cartStore.ts
interface CartStore {
  items: CartItem[]          // { productId, name, price, qty, stock }
  addItem(product, qty)
  removeItem(productId)
  updateQty(productId, qty)  // capped at product.stock
  clearCart()
  totalItems: number         // derived
  subtotal: number           // derived
}

Persisted to localStorage via zustand/middleware/persist. Synced to server cart on login.

checkoutStore.ts
interface CheckoutStore {
  step: 'address' | 'payment'
  selectedAddressId: string
  newAddress: AddressForm | null
  razorpayOrderId: string
  setStep(step)
  setAddress(id)
  setNewAddress(form)
  setRazorpayOrder(id)
  reset()
}

Not persisted. Reset after successful order. Step drives checkout route rendering.

💡 Design Principles

Mobile-First
  • All grids collapse to 1-col below 640 px
  • Touch targets ≥ 44 × 44 px (WCAG 2.5.5)
  • Sticky header + floating cart button on mobile
  • Bottom sheet for filters on mobile
Next.js App Router Patterns
  • Catalog + Product Detail: Server Components + generateStaticParams
  • Cart, Checkout, Orders: Client Components ('use client')
  • Homepage: ISR with revalidate: 3600
  • Auth routes in (auth)/ route group with own layout
SEO & Performance
  • Product detail pages: generateMetadata() per slug
  • Images via Next.js <Image /> from Cloudinary
  • Catalog: URL search params for shareable filter state
  • Structured data (JSON-LD Product schema) on detail page
Auth Guard
  • Cart: local Zustand only (no auth required)
  • Checkout: redirect to /login?redirect=/checkout
  • Orders + Profile: middleware-level redirect
  • Google One Tap: shown on any public page, dismissed if logged in
